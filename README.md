## 尝试使用QFramework复刻经典小游戏 FlappyBird练手

### 需求分析

- 主角（鸟
  - 按下空格则跳跃
  - 碰到水管则游戏失败
  - 通过水管则积分+1
- 水管
  - 随机生成
  - 水管之间的宽度，和上下水管的距离可以控制难度
  - 水管向左移动的速度控制难度
- 机制
  - 最高分

### 开发流程

1.快速实现机制需求 美术从简 方块圆圈代替

2.加上美术和音效等素材

### 开发

- 小鸟
- 脱离屏幕
- 小球碰撞器
- 闭环
  - 游戏开始
  - 游戏中
  - 游戏结束（失败）
